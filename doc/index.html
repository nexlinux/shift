Nex Linux Package Manager

shift

A hybrid source & binary package manager built for Nex Linux. Compile from ports or install prebuilt binaries — your choice.

Get Started Browse Ports

Why shift?

The power of source builds with the speed of binary packages.

⚡

Hybrid by Design

Use --bin for instant installs from precompiled packages, or --port to build from source with your own flags.

🔗

Smart Dependencies

Automatic topological resolution. Build deps, runtime deps, and circular dependency detection out of the box.

🛡️

Config Protection

Never overwrite your /etc files blindly. shift creates .shift-new backups and lets you decide.

🔍

ELF Verification

After every install, shift runs ldd to verify all shared libraries are present and accounted for.

📦

Binary Builder

Build once, distribute everywhere. shift --port build-binary pkg creates a .tar.zst for your repo.

⚙️

OpenRC Native

Built on Gentoo Stage 3 with OpenRC. Detects new init.d services and reminds you to rc-update add.

Quick Start

Initialize, sync, and install in under a minute.

Terminal 
# Initialize shift directories and config
sudo shift init

# Sync the ports repository
sudo shift sync

# Install a binary package
sudo shift --bin install curl

# Or build from source
sudo shift --port install curl

# Upgrade everything
sudo shift --port upgrade

Recipe Format

Simple YAML. Powerful builds.

📋 curl/recipe.yaml

name: curl
version: 8.5.0
source:
  url: https://curl.se/download/curl-8.5.0.tar.gz
build:
  - ./configure --prefix=$PREFIX --with-openssl
  - make -j$(nproc)
  - make DESTDIR=$DESTDIR install
depends:
  runtime:
    - openssl
    - zlib
provides:
  - bin/curl
  - lib/libcurl.so.4

📋 openssl/recipe.yaml

name: openssl
version: 3.5.7
source:
  url: https://openssl.org/source/openssl-3.5.7.tar.gz
build:
  - ./config --prefix=$PREFIX shared
  - make -j$(nproc)
  - make DESTDIR=$DESTDIR install
depends:
  build:
    - perl
provides:
  - lib/libssl.so.3
  - bin/openssl
